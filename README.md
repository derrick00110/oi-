# oi事实监测播报

本地工具。读币安 U 本位永续的公开行情，用持仓数量和同一段时间的价格变化判断多空，越过阈值就用中文播出来。

不需要币安 API Key。扫描不会下单。手动下单是单独的一步，默认关闭。

## 五条事实

判断用的是持仓币数 `sumOpenInterest` 的涨跌，不用持仓价值。持仓价值里含着价格，价格一涨，价值也会涨，用它会把多空看反。

| 持仓数量 | 价格 | 播报 |
| --- | --- | --- |
| 涨 | 涨 | 多头主导，看涨 |
| 涨 | 跌 | 空头主导，看跌 |
| 涨 | 震荡 | 看不清，配合费率再判 |
| 跌 | 涨 | 空头止损拉盘，大概率出向上的针 |
| 跌 | 跌 | 多头派发第一阶段，可跟空 |
| 跌 | 震荡 | 先不判方向，播报仍带资金费率。这不在上面五条里 |

价格绝对涨跌小于震荡带就算震荡。默认 0.5%，页面上可以改。等于 0.5% 算涨或跌，不算震荡。

价格震荡时，播报会带上当前资金费率。费率为正是多头付给空头，为负是空头付给多头。工具只报这个事实，不替你把费率再判成多空。

门槛按持仓价值分档，用的是持仓数量涨跌，不是持仓价值涨跌：

- 500 万到 1000 万：10%
- 1000 万以上到 1500 万：5%
- 1500 万以上：5%
- 不到 500 万：不按比例播

四种形态：

- 持仓涨、价格涨：优先推报，做多信号
- 持仓涨、价格跌或平：可能为出货、洗盘或蓄力
- 持仓跌、价格跌：弃盘行情，需观望
- 持仓跌、价格涨：需观望。图上没有把它列为做多

另外两条特殊提醒：过去 60 分钟持仓价值翻倍，并且现在至少 500 万，标成最高级别。持仓价值从 2000 万以下跨到 2000 万或以上，单独报关键分水岭。

价格绝对变动小于 0.5% 算平。扫描默认看成交额前 400，大范围结果缓存 5 分钟。

## 用到的公开接口

都是币安现在公开、免费的行情接口，按 IP 限制访问次数，不按账户收费。

U 本位合约：

- `GET /fapi/v1/exchangeInfo`：找出正在交易的 USDT 永续
- `GET /fapi/v1/ticker/24hr`：最新价、24 小时涨跌、成交额。不带 symbol 时一次返回全部，权重 40
- `GET /fapi/v1/premiumIndex`：标记价格和 `lastFundingRate`。不带 symbol 时一次返回全部，权重 10。不按币种去拉资金费率历史，那条线另外限 500 次 / 5 分钟
- `GET /futures/data/openInterestHist`：`sumOpenInterest`、`sumOpenInterestValue`、`CMCCirculatingSupply`。周期用 `15m`。这条线的 IP 限额是 1000 次 / 5 分钟，程序本地先卡在 800 次 / 5 分钟

合约 IP 权重大约 2400 / 分钟，响应头 `X-MBX-USED-WEIGHT-1M` 能看到已经用了多少。持仓历史不走这套权重，单独计数。

现货 REST 没有未平仓量。这套判断比较的是合约持仓和合约价格，所以不去打现货接口，避免多占请求次数。

## 运行

需要 Python 3.10 或更新版本，没有第三方依赖。

```bash
cd binance-oi-monitor
python3 server.py
```

浏览器打开 http://127.0.0.1:8765

只在终端看一眼：

```bash
python3 server.py --once --limit 30
```

`--limit` 按 24 小时成交额取前 N 个合约，也可以写成 `all`。默认 400。全市场大约 500 次持仓历史请求，会顶到 5 分钟限额，所以大范围结果缓存 5 分钟。

## 播报

服务启动后每 60 秒看一遍缓存。同一根 15 分钟快照不重复播。勾选「语音播报」后，新消息会用浏览器中文语音读出来。打开页面时不会把历史消息再读一遍。

一条消息的样子：

```text
🟢 [BTCUSDT] 币安未平仓合约量 +6.5%，过去 3600 秒价格上涨 5.2%，未平仓合约量：76.00 亿美元，未平仓合约量/市值比率：0.5%，24 小时价格变动：-4.2%。多头主导，看涨
```

绿点是看涨或空头止损拉盘，红点是看跌或多头派发，白点是价格震荡、先看费率。

## 手动下单

下单接口只接受本机访问。默认 `TRADING_ENABLED` 不打开，播报线程不会发单。需要连你自己的账户时再说，公开监测用不到 API Key。

## 网络

程序会先试 `https://fapi.binance.com`。如果当前网络被币安按地区拒绝，会改走 `https://www.binance.com` 上的同一套公开接口。

```bash
export BINANCE_FAPI_BASE=https://fapi.binance.com
export https_proxy=http://127.0.0.1:7890
python3 server.py
```
